# Summon and trap stat snapshots

The approved Sanctuary rule applies across all classes, including Assassin traps: capture each summoned unit's inherited base stats and ranks when it is created. The user settled Poison Creeper with “just snapshot it on being summoned” and extended the rule to all summons. See [the decision](../tools/reference/summon-snapshot-decision.json). This is an explicit adaptation where the exact D2R 3.3.93847 capture timing is uncertain.

Snapshot the effective summon rank, relevant hard-point synergies and the stats explicitly inherited by that skill. This does not grant every pet all of its owner's equipment effects. For example, traps keep their declared inherited passives, while Poison Creeper does not inherit the owner's poison mastery or ordinary item resistance pierce. Capturing a sunder value does not establish its damage consumer; unsupported delivery stays explicit.

Existing summons and already-issued fields/projectiles keep their stored values when the owner changes gear or trains more points. A new summon gets the newer values. Normal external buffs and auras remain separate effects; Battle Command can affect an NPC's next innate skill invocation without rewriting its base snapshot. Approved facet difficulty rescaling still occurs with the same current-life percentage. Parking, wounds, timers, class permissions and ownership retain their existing rules.

Historical save profiles keep their interpretation. Missing historical values need an explicit migration rule; do not silently reconstruct old base stats from the owner's current build on every read. Poison Creeper's new approved profile coexists with its older source and balanced profiles, and old fields keep their packets and random streams.

The cross-class rollout is not complete. Learned Necromancer Warriors, Mages and all four golems now publish their born upgrade hard points through optional supplement 192. Their existing captured dictionaries/recipes supply the values; current births do not reconstruct them later. Older missing-supplement actors keep the documented legacy live rule until resummoned. See [Warrior acceptance](warrior-snapshot-checkpoint.md) and [Mage/golem acceptance](necro-snapshot-checkpoint.md).

Druid beast casts capture Spirit Wolf, Dire Wolf and Grizzly upgrade hard points and uses their existing effective birth rank for later mode-stat setup. See the [checkpoint](druid-snapshot-checkpoint.md) for verified acceptance. Raven still reads owner stats for attacks and initial budget; audit those reads and other class consumers before claiming the global rollout complete. Existing birth records and trap passive snapshots should be reused. Do not mark a pet/class finished merely because it has a birth record.
