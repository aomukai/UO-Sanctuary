# Frozen NPC equipment combat suppliers

Reference: **D2R Reign of the Warlock 3.3.93847**, approved Sanctuary deviations first. This prepares the independent equipment data required by the approved Revive rule: leave original gear lootable and preserve combat effects separately. **Equipped Revive remains gated.** NPC attachment, resource/combat consumers and events still need integration; this checkpoint does not complete that skill or class.

The existing version-0 frozen equipment JSON gains an optional `CombatJson` field. Converted originals capture the existing live `ItemStatContext` projections for all 99 recipient levels: elemental endpoints/cold frames, poison rate/range/duration/count, exact fractional resource inputs and per-level coefficients, and separate one-/two-handed melee endpoints. Weapon type, slot and attribute coefficients are captured without a live item reference. No item is reconstructed, moved or rerolled by capture or binding.

Raw numeric stat projection is a separate capability. Existing source adapters report unsupported `fireskill` and combined `dmg-cold` properties. Their complete original property/roll data and an explicit raw-projection issue remain saved; requesting the raw stat list refuses instead of returning an invented empty working list. Independently supported typed/resource/physical suppliers remain readable. A failure of the supplier capture itself has its own explicit issue and does not discard the existing basic gear/property snapshot. Existing equipped-Revive admission and live Iron Golem consumers are unchanged.

Missing optional fields remain readable: historical snapshots keep their existing basic suppliers and refuse new combat access rather than reconstructing values from changed/deleted loot. New payload validation rejects missing levels, malformed tails, invalid versions, unsupported-data contradictions and invalid typed channel/length shapes. Returned raw arrays are cloned; immutable snapshots survive changes to, or deletion of, their original items.
