# Bind Demon cast orchestration

Reference: D2R Reign of the Warlock **3.3.93847**, with approved Sanctuary deviations first. The complete current **709-byte do158** routine is implemented as `BindDemonCast`. This is a prepared component, not a playable Bind Demon: its target gate and binding operation remain mandatory unresolved services.

The routine reads the skill row, marks the caster's action flag, refreshes its existing path target, rejects missing/self targets and checks the state index against the selected table. It then calls the supplied eligibility gate. A declined eligibility gate returns **1**, without the later conversion work. This return value alone does not establish channel success or payment.

An accepted target goes through the source AI-stop branch. Where applicable, the routine caches its encounter counter before reading the target's alignment/value and increments it with unchecked arithmetic. It invokes the transfer helper, walks the target's event list using each next link captured before release, clears the list head, resolves the current owner through the typed registry and selects the source stop callback. It reads the caster's current context only immediately before the binding helper. Successful binding sets the source target/data flags and calls the room-update service. Declined binding also returns **1**, preserving preceding mutations rather than rolling them back.

Existing `GenericPetAiGame`, `GenericPetPathTarget` and `GenericPetOwnerControl` views are reused. New views expose only fields actually consumed by this routine; they are not persistent controllers or live native state producers. Refresh, eligibility, AI stops, encounter counter/value, transfer, logical event release, registry, binding and room updates remain declared services. No native monster is converted or stripped of its real event list by this component.
