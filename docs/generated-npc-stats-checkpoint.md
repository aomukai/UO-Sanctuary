For Shadow monsters, the source has no player main-weapon lookup and suppresses damage-related weapon stats in the shared actor graph; individual weapon contributions remain available for the later selected-hand damage consumer. The older player policy does not establish modern Warlock player behavior.

`GeneratedNpcStatGraph` restores the original native item-owned raw graphs in inventory order and binds them to an actual recipient identity through the existing `EquipmentStatGraph` and `EquipmentStatValues`. It requires explicit source base fields, world-clock service, value-change handler, animation-rate handler and vital-clamping handler. It does not import UO attributes or replace those callbacks with implicit native setters. Reads use the existing cached operative source reader. Repeat updates, recipient level changes and logical stat removal preserve topology, damage inclusion, derived fields and callback order. Changes to physical inventory, owner or saved item payload invalidate the frame.
