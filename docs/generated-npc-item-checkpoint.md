# Generated NPC item serialization checkpoint

Reference: **D2R Reign of the Warlock 3.3.93847**, with approved Sanctuary deviations first. Parent `005657aa` is pushed. Coverage remains **197/240 handlers**, no completed class or deployment.

`GeneratedNpcItem` materializes the qualified prepared component as a real native item with its own world identity and serializer. Its payload contains the original request, final quality/graphics/name/affix metadata, unit and item seed states, base stats and ordered property contributions. Creation reuses `CurrentItemQuality`; it does not enter the player gear factory, project through `GearState`, reroll a saved value or filter the selected property pool. Unsupported requests reject before allocating a world item; a failed creation deletes its new identity.

Native serialization retains the payload directly on the item. The item decodes an isolated snapshot on each read, validates the schema/reference version, graph structure, quality/variant fields and reference affix/name/automagic identities, and rejects malformed state. Restore requires explicit graph services and performs no property draws. Editing a returned snapshot or transient graph does not alter the item's saved payload. This is an unattached item creation boundary: player lift/equip/trade routes refuse, and NPC delivery remains separate.

**2,580 original native items** cover every one of the **516 qualified bases** at requested qualities 1/2/3/4/6. Native checks compare them against the independent source cases, including fallback metadata, all raw fields, both final seeds and the next HP-property roll. Three boots, two reloads and three saves verify actual item-owned payload restoration. The fixture manifest contains case/identity/equality witnesses only; it never restores an item graph or metadata. Invalid contexts, malformed payloads, alias isolation and deletion are also checked. The existing 2,624 prepared fixtures, 1,680 affix fixtures, staffmods, finishing and earlier pipeline checks remain in the same compact cohort.

This presentation placeholder does not block raw mechanics or serialization, and does not establish a skill effect, audio cue or talent/hotkey icon.

Scope remains format 100, explicit separate initialized seed streams, requested qualities 1/2/3/4/6, the NPC no-sockets/never-ethereal flags, and nonquest/nonunique body-equipment bases.
