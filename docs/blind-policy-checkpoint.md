# Blind AI decision foundation

Reference: **D2R Reign of the Warlock 3.3.93847**; approved Sanctuary deviations take precedence. This new C# component is **not connected to live skill behavior**. The [Dim Vision cast checkpoint](dim-vision-cast-checkpoint.md) remains the latest accepted runtime milestone. Full blind AI, skill and class completion remain unproven.

`BlindAiPolicy` translates the target-mode-1 no-target request, shared blind tick decision and random displacement contract into C#, using supplied target/table/combat/world flags and RNG services. It reuses the existing source algorithm contract rather than attaching pet equipment ownership to ordinary monsters. No RNG store, timer, target acquisition, mode entry or path callback is implemented by this component.

With no target, escape/collision plus an available walking mode requests distance-5 displacement. Otherwise it requests 10 frames of idle below source distance 25, `distance − 10` for 25–34 or 25 frames for 35 and farther. This branch makes no percentage call. With a target, eligible ordinary melee requests an attack without RNG; other cases make exactly one percentage call for 20% distance-3 displacement versus 10-frame idle. The displacement helper makes three raw and one bounded draw in the source axis/offset/sign order. Requests grant neither an immediate hit nor movement.

The [source receipt](../tools/reference/dim-vision-ai-source-evidence.json) executes 12,288 complete tick/walk-near and 224 complete acquisition-wrapper contexts under ASan/UBSan. Table/dispatcher/idle/mode-entry helpers remain static review. Target acquisition, collision, mode entry, event timing and RNG services remain declared. The new native fixture compares every tick/tactics row and the **112 no-target rows** of the wrapper matrix; its target-present rows are not counted as separate native wrapper verification. The ordinary tick matrix supplies the target-present decision comparisons. Wander offsets are compared at the source tick's distance 3; live distance-5 geometry still needs world verification.
