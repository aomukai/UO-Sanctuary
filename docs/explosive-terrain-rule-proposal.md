# Fire Ball / Glacial Spike native terrain proposal

Status: **prepared, disabled by default, awaiting an explicit Sanctuary decision**. Reference remains **D2R Reign of the Warlock 3.3.93847**. This defines a Britannia terrain mapping; it does not claim recovered D2R impact coordinates.

Use the existing `LobProjectiles.Advance` adapter already shared by Fire Blast and Shock Web for **Sorceress Fire Ball and Glacial Spike** movement. It scans ordered source half-cell crossings, honors native Wall/NoShoot tile metadata, height, map bounds and segment LOS, and terminates at the last clear native tile before a barrier. A terrain termination wins over a monster contact within that same update. It produces exactly one existing copied-area explosion there, with existing recipient LOS/resistance/avoidance and Glacial freeze. No extra direct hit or wall damage packet.

When no terrain blocks movement, retain fractional position, velocity, captured Slow Missiles, lifetime, contacts and expiry. Keep the existing damage/RNG, radius, mana, buffs, snapshot, owner lifecycle and saved version0 flight shapes. The adapter runs on each active movement update, so a newly closed door is evaluated through its current tile/LOS state. The proposal adds no flight-origin field, recovery, lifetime reset or save migration.

The candidate is guarded by `SorceressSpellMissiles.PreparedExplosiveTerrain`, which defaults false. Tests opt in temporarily and restore false. Ordinary learned routes retain the characterized older wall behavior until adoption; learned-input qualification under the adopted rule follows a decision. Existing default Fire Ball/Glacial real inputs and saves are retained as regressions. No other explosive controller or NPC/mage projectile is silently changed; those may reuse this adapter in their own follow-up. Other class proposals remain independent.

Prepared native verification covers eight wall directions for each spell, caster-side damage and far-side occlusion, Fire Ball versus Glacial freeze, open contact/expiry copied packets, and original held flights/resources across two reloads with resumed moving copies. Existing source-number and ordinary wire regressions remain. The stable [checkpoint](explosive-terrain-checkpoint.md) will bind the exact completed result. Effects/audio and icons keep their existing separate placeholders; this proposal adds no art requirement. No charms, runewords, current D2R reads or installed changes.
