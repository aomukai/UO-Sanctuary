# Safe-area persistent army parking

Reference: **D2R Reign of the Warlock 3.3.93847**, with the approved Sanctuary parking policy taking precedence. Follows `2f764ba`. This increment has the scoped verification below; no class completion or deployment is claimed.

`MinionSafeAreas` reuses native SafeZone/active GuardedRegion classification through `SpellHelper.IsTown`, independent of roofs or ordinary indoor regions. Movement/map-change subscription runs during Initialize so existing map-survey and difficulty hooks remain. Persistent armies use the existing class-switch parked flag, ownership, saved follower-slot and expiry ledger. The named companion is identified through the mercenary profile service. Actors outside the persistent-army behavior registry, including short-lived traps, keep their separate rules.

Entry internalizes the same actors and cancels pending actions through existing suspension. Resume/load/login, CanThink, native Revive admission, the shared ground controller, stationary sweep and completed Necromancer creation commits enforce the same safe-area refusal. Existing class/permission/owner/expiry checks still apply. Return finds a real landing before restoring released slots. Difficulty changes retain the existing proportional-life policy.

Parking settles the preceding active interval once. Parked restoration lanes consume their original duration/units without paying life or mana; newly accrued fractional recovery is discarded rather than paid later on return. Poison and Open Wounds retain their clocks and ordinary receiver admission. Positive item replenishment is masked before combining it with harmful periodic damage, preserving negative item rates; positive direct regeneration also refuses parked actors. Return settles the parked interval before changing admission. No status is cured or given a fresh duration. Existing native Revive suspension/Blessed admission remains unchanged; this does not claim a new periodic-damage entitlement against a receiver already protected by that native policy.

The explicit healer context-menu action can reach living owned parked actors without spawning them. It retains existing provider/access/proximity/peace rules. Automatic conversation/trade calls retain their ordinary nearby-pet behavior and do not gain parked-roster access. Healing does not add a new cure or resurrection rule, price or mercenary entitlement.
