## Boundaries

This is native world adaptation, not recovered D2 Lich behavior. Eligibility analogue, no-regen, native weapon fallback/cadence and dependent helper cleanup belong to the one complete proposal. Existing native startup/load and in-flight missile ownership behavior remain explicit; the global UO-to-D2 monster-spell conversion is separate. Other native types, old incomplete corpses, unsupported elites/controllers/equipment and inherited nonzero Sunder retain their refusals.

No class is certified; handler coverage remains 236/240. Learned native input acceptance follows adoption. Four older Warlock proposals remain frozen. Installed build/configuration/saves, native kernel and client are unchanged. Final Revive/undead effects/audio and talent/hotkey icons remain separately tracked, using the existing identified placeholders.
