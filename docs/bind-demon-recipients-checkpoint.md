Prepared integration against **D2R Reign of the Warlock 3.3.93847**, with approved Sanctuary policies taking precedence. The [original host](bind-demon-host-checkpoint.md) and [typed packet adapter](bind-demon-typed-checkpoint.md) remain the foundation. Coverage is **226/240 handlers, Warlock 17/30; no class certified**. Neither Bind Demon nor the pending Blood Boil adaptation is admitted by this change.

`WarlockDemonRecipients` supplies a shared, qualified recipient roster using the actual native bodies. Original Goatman, Tainted and Defiler retain their learned-state, permitted-owner, fault-free controller and active Death Mark world checks. An original bound NPC instead requires its saved bound identity, owner, creation order and existing native-host activation. It does not pretend to have a `SkeletonGuardian` body or the original summons' source controller. Ownership, persistence permission, active class, equipped-context refusal, parking, facet, blessing, town and online checks remain explicit. Callers choose their own range. The roster sorts all qualified original and bound bodies together by saved creation order, then serial. It is distinct from the replacement pool: an inactive or unqualified member still occupies its saved slot.

This does **not** install Engorge effects on bound NPCs; its storage/recovery/leech qualification is still unfinished.
