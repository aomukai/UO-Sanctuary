Reference: owned D2R Reign of the Warlock **3.3.93847**. Source root composition is implemented and focused-native verified. This checkpoint does not enable the learned summon or the automatic world controller.

The new binding composes the existing GenericPet initialization, owner census, gather, search wrapper, preparation, resistance-aware target scoring, rating routing, weighted selection, action disposition and follow executor. Goatman's current profile has `ChooseType1` and five possible actions once all four internal skills unlock; its normal attack remains a source base-mode candidate.

Four bounded score/action-flag records are copied from the retained owned429-row,748-byte compiled skill table. The file hash matches the previously authenticated metadata extraction. AI and damage share the existing persisted actor random stream. This prevents AI selection from overwriting random advances made by damage, critical or Crushing Blow callbacks. Target scoring reads the target's resistance pool without transferring the owner's equipment or attack-specific piercing.
