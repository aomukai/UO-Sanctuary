# Bind Demon action and world rule — proposed Sanctuary adaptation

**Approved by the user — 2026-11-15 JST.** [Decision record](../tools/reference/bind-demon-world-rule-approval.json). Learned admission and socket verification are now authorized; the target limits below remain explicit. This defines the complete player-action rule for the currently qualified native-body path. It does not certify every native species or finish the class roadmap. Reference remains **D2R Reign of the Warlock 3.3.93847**; approved Sanctuary rules take precedence.

The pinned startup, eligibility and binding callbacks remain unavailable. The installed newer D2R version cannot substitute for that pin. The existing 709-byte do158 observation supplies orchestration evidence, but does not prove current payment, channel progress, raw chance-variable context or native UO mapping. The following decisions are explicit adaptations for review.

| Stage | Proposed behavior |

The fixed nine-mana rule is a deliberate proposal. The pinned shifted table costs are **200/256 at rank 1 and 276/256 at rank 20 per invocation**; they do not establish a current invocation cadence or prove a flat nine-per-second cost at every rank. The grouped health expression also deliberately differs from the older compiler-port interpretation. Approval would adopt these defined choices, not turn them into claims of recovered D2R behavior.

The successful host uses the existing prepared stat and lifecycle services:

- Apply pinned captured Bind, Demonic Mastery and Blood Oath suppliers through the current native damage, accuracy, armor, speed and resistance consumers. Keep the separate inherited physical-sunder fields; nonzero delivery remains unsupported.
- Use the original unbuffed Normal life baseline and existing difficulty projection with the prepared players-one context. Apply the bound-life cap before existing Battle Orders/Oak bonuses. Preserve current life percentage on binding, buff changes and owner-facet changes; no mana/stamina refill or healing reset.
- Grant effective-rank 5/10/15/20 upgrades using the existing Extra Strong, **movement-only Extra Fast**, Spectral Hit and captured aura services. Use the existing encounter aura chooser/level-rank mapping, save its choice, and do not claim D2R seed/initializer parity. Shared Battle Command may temporarily raise effective aura rank without rewriting birth.
- Allow one bound demon inside the existing shared demon pool. Hard Demonic Mastery controls pool capacity; saved creation order controls replacement. Preserve the prior bound demon until a successful new binding commits. Retired originals and their inventory follow the existing replacement/deletion rules; no duplicated loot or new corpse is created by binding.
- Reuse existing persistent-minion ownership, safe-area parking, owner death, logout, facet travel, save/load and native AI resume. Parking grants no recovery or reset; ordinary timed effects retain their expiry. Bound creatures retain their original native abilities until the separate monster-spell conversion work replaces them.
- Reuse the already prepared bound-recipient integrations for Death Mark and the separately pending Blood Oath, Engorge, Blood Boil and Consume proposals. This decision would not approve those four independent proposals.

The current audit finds 35 native demon type candidates: 22 have compatible source data and thirteen need species mappings. This is an inventory, not proof that all 22 live actors pass every ownership/controller/combat guard.

The current world boundary is explicit. Ordinary live actors must have a qualified current demon classification, a compatible pinned Bind species row and all difficulty projections. Native Paragons and explicit native elites are refused until their quality/stat adapter exists. Unmapped reward analogues, named-source hosts and underling-owning species are also refused. Existing dungeon encounters are explicitly undead rather than demon. No type, hue, name, level or new minion pack is invented to disguise those gaps. Sunder-bearing named items are currently unavailable; recipe-only renewed charms remain a future acquisition/consumer boundary. These limits stay on the roadmap after core admission; approving this proposal does not declare every Bind target context complete.
