# Approved mechanical decisions and implementation discretion

Approved 2026-11-18 JST. These decisions refine the pinned D2R Reign of the Warlock 3.3.93847 reference requirement; they do not change the class-skill objective. The [decision record](../tools/reference/class-mechanics-intent-decision.json) preserves the user's answers.

1. **Bash:** adopt the reviewed flat-damage rule. Add captured `calc2` after weapon percentage damage and critical/deadly-strike multiplication, before shared mitigation/absorption, on successful unblocked contacts. Physical event and life-damage budgets must agree. The tested proposal is approved; learned-route wiring and qualification remain to be completed.
2. **Find Item targeting:** use the existing nearest eligible corpse helper, within two tiles of the cursor and the existing eight-tile caster range, preserving LOS and safety checks. Acquisition failure costs nothing; do not add automatic walking. The user clarified that D2 itself requires clicking a corpse. Sanctuary's near-click targeting is an explicit quality-of-life adaptation.
3. **Find Item eligibility:** use a corpse's captured supported loot profile. Exclude quest corpses and explicitly designated bosses. Missing/unsupported loot context refuses before mana payment. Champion/unique corpses are eligible only with their proper captured context; do not fabricate loot.
4. **Unrecoverable reference details:** choose the closest existing verified Sanctuary mechanic according to intended behavior, document the adaptation and test it. Preserve approved decisions and pinned numerical values. Ask about substantial new balance changes rather than returning for each minor engine/world-mapping choice. This supersedes the earlier need for individual approval on every such minor adaptation.

When mapping native UO creatures, use the closest intended D2 role or relative-strength category. Combat strength alone does not grant boss/unique attributes, immunities or special flags. Unsupported source details should remain visible as provenance limits; use the approved intention-based rule rather than leave ordinary mechanics indefinitely undecided.

World-density balance is a later discussion. The user described ordinary UO monsters potentially approaching D2 unique-minion strength, without unique attributes, with appropriate XP/drops. A global ordinary-monster modifier or a "players 5" baseline is a possible later option because UO dungeons cannot always accommodate 10–20-monster packs. No multiplier or players-setting change is approved for implementation now. Its effect on boss-killer versus density-cleaner builds must be discussed separately.

Finish the existing class-skill goal before opening smaller goals. Preserve the working build and saves, use focused tests for actual changes or uncovered requirements, and keep final effects/audio/icons separately tracked. This decision does not authorize charms, runewords or the separately deferred global monster-spell conversion.
