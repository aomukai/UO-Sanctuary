# Original Revive persisted offensive stream

Reference: **D2R Reign of the Warlock 3.3.93847**, approved Sanctuary deviations first. Prepared original Revives now use the existing persisted NPC source-algorithm stream for offensive computation. This adds stream ownership and continuation; original-body swing interception, ordered impact/events and equipped learned admission remain unfinished.

The existing version-0 `NpcEquipmentSeed` gains optional `ReviveCorpse` and `ReviveBinding` fields. Default fields are omitted, so original-item and unarmed rows keep their previous serialized shape and behavior. A frozen binding has Item zero and Unarmed false; it is distinguished by the original corpse identity and a fingerprint of the immutable before-death JSON. The fingerprint is cached with the already-bound equipment context, rather than hashing the payload on every random draw. No item object or loot-corpse lookup is required. A changed death snapshot cannot reuse a stale stream merely because serials match.

`ReviveEquipmentOffense.Roll(actor, target)` first captures every supported offensive input, then invokes the same limited/raw NPC random service as existing summon consumers. Unsupported capture does not initialize or advance the stream. Initialization uses the established SeedLow/SourceRandom policy once per binding; this does not recover or claim the historical D2 world seed or full native AI random chronology. Facet rescaling, parking and loot/corpse deletion preserve the binding and current seed. Old original-item and unarmed services retain their own matching rules.

Stream restore validates all rows before replacing the registry. Frozen rows reject missing/invalid fingerprints, mixed live-item/unarmed fields and partial bindings. Replacement, failed activation and original/owner death now explicitly forget the stream and frozen context. This also closes a cached-context cleanup gap when an old Revive was replaced. Lifetime remains the approved rule: no expiry timer; death, owner death or replacement ends the original.

The native checks reuse the three real original-body offensive fixtures (one-handed, two-handed encounter and unarmed) with already-deleted loot. Each stream is lazily initialized once, follows 256 exact source draws and produces the same packet/final seed as an explicitly supplied stream. Invalid bounds and unsupported bodies do not advance it. Whole-registry malformed restores remain atomic. A new death epoch with the same actor/corpse serials rebinds, while returning from the probe restores all prior streams. Normal/Hell travel and internal parking retain them. A separate rank-1 owner proves actual corpse deletion, summon replacement and Necromancer death clean up correctly. Both actual reloads consume the expected next draw without reseeding, perform an offensive roll and save the next generation.
