`GenericPetTimedEvents` models supported monster events with a null callback. It retains event type, signed due frame, three payload words, processing/removal flags, each unit's newest-first event list and the monster group's 64 frame-remainder buckets. Creation inserts at the head of both lists. Removing an ordinary node unlinks it and returns its handle to the available stack; removing a processing node sets flag 8 and leaves it linked. Actual dispatch completion, global traversal cursor and allocator/pool growth are outside this prepared store's scope.

Ordinary scheduled frames at or before the current frame clamp to the next frame using the source signed comparison and unchecked addition. An explicit requested frame of -1 takes a separate original untimed path; this adapter refuses it. Negative event types and missing/invalid actor identities also refuse. The current monster-group mapping is pinned from the owned executable. Other unit groups and non-null callback validation are not inferred.

The current AI-event scheduler also has a special stat-root branch: table count greater than 54, root field +1c negative and flag 0x400000 at +b34 invoke a supplied service. It then re-reads mode and unit flags, refusing allocation for flag 0x10000 or monster modes 0/12. These raw conditions are preserved without inventing a gameplay interpretation or silently defaulting live metadata. Source selector errors remain explicit refusals.

Idle uses one frame when its input delay is zero. If the unit is not neutral, it first requests the existing neutral transition. It then removes only type-2 AITHINK events, caching the traversal before removal, and makes a new null-callback request. Other event types remain. Negative delays still reach the scheduler's source frame clamp. The live context provider is queried after transition/service changes; no stale pre-transition status is substituted.
