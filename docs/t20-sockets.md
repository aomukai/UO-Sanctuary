# T20 — Tinkering empty sockets

Implemented and deployed 20 October 2026 JST. The rules and the user's clarified intuition choice are recorded in [crafting.md](crafting.md) and `data/Sanctuary/Balance/tinkering-sockets.json`.

At a public Tinkering workbench, use owned functional tinker's tools and choose **Add one socket**. Target identified Drop/Crafted gear in your backpack. Head, body, weapons and shields accept up to five total sockets, independent of rarity or base tier. Native crafting-quality sockets count toward the next socket. Gloves, boots, jewellery, tabards, cosmetic cloth hats, starter/protected/vendor gear and ground items are excluded.

Both skill gates apply: Normal/Exceptional/Elite require 30/80/100 trained Base Tinkering, while socket1/2/3/4/5 requires 30/50/70/90/110. Base success is 100/50/25/5/5%. Crafted Average/High Quality/Superior tinker's tools add 1/2/3 percentage points, capped at 100%, retaining 100/110/120 charge capacity. Shop and untracked legacy tools add 0. Active Tinkering and the normal production readiness checks are required.

A performed attempt costs one tool use, subject to the existing 10% crafted-tool saving. There is no gold/material fee. Success adds exactly one persistent `TinkerSockets` unit, preserving native sockets, identity, affixes, quality, item/equip level, material benefits, maker, wear, origin and resale quotes. It offers the ordinary native skill-gain check from the required skill through required+50, respecting lock and cap. Failure destroys the host and all its contents. Confirmation states the odds and destruction risk; white gear has an explicit warning that any Tinker socket permanently blocks later Imbuing. Native quality sockets alone remain eligible for Imbuing.

At 120 skill, a failed roll has a 5% intuition chance **before acting**. The crafter draws back: the item is unchanged and the initial attempt costs no use. A separate screen offers **Retry once** or **Abort — keep item**. Abort closes safely with no charge or socket. The chosen retry uses the same odds and ordinary tool-use cost/saving; failed retry destroys the item and cannot offer another intuition. Cancelled, stale or replayed confirmations do nothing.

The server binds each confirmation to its player, connection, current session, profession selection, trained skill, actual tool/uses/profile, original item metadata and complete native contents. It rechecks ownership, protections, public workbench, cooldown, cap and gates before random outcomes or consumption. Legacy previews are read-only until success, avoiding metadata changes on cancellation or intuition. Existing gear/tool save formats remain unchanged. Rune/gem insertion and effects remain T25/T26.

Verification uses disposable worlds and the actual ClassicUO client. `SocketChecks.cs` exercises all 15 tier/index gates, success/failure boundaries, native contents destruction, supported categories/rarities, crafted bonuses and charge saving, free intuition/abort/paid terminal retry/last charge, stale work, Imbuing provenance, legacy preview and save/reload. The tool menu stays within its existing 400-pixel panel, with the Tinkering practice rows compacted to leave room for socketing; its position remains shared consistently with other tools. The new socket confirmation also fits a 640×480 game window. The client fixture supplies item targets and seeds the rare initial intuition; real mouse clicks exercise the tool menu, white warning, cancellation, first-socket success, intuition abort and paid retry.
