## Implemented

Ordinary learned Holy Shield now follows distinct start36 and do18 phases. A successful active-shield gate and ordinary action admission pay **35 mana once at start**. A transient session ticket authorizes the effect event; it is consumed once and is never serialized. Do18 does not charge again. Movement, Stop, equipment changes and the existing owner/action guards cancel the ticket. Paid cancellations do not refund the start cost. Exact current player-mode and equipment-switch semantics remain bounded by the existing host adapters.

An active stronger same-skill state rejects a weaker effect after its already-paid start. Equal rank refreshes values and deadline; higher rank replaces it. Holy Shield has no state group, so it preserves group1 cold armor. The effect stores its rank and block bonus; defense continues to evaluate current hard Defiance at the stored rank. Shield-dependent block, defense and Smite consumers are reused. Taking off or breaking the shield disables those consumers while preserving the existing timed state; re-equipping or repairing resumes that same state. Live requirement-loss handling remains part of the shared equipment-contract gap.

Route checks pin skill117/start36/do18, holyshield/toblock, UseManaOnDo0, right-only mouse policy, fixed mana and supported rank/block/duration inputs. The ordinary effect uses the existing release-time effective-rank query; full modern used-skill rank/mode refresh is not certified. Bare do18 has no second shield gate; actual client actions also follow the host's equipment-cancellation callback. The component tests distinguish those paths explicitly.

Persistence remains version0 with the same Owner/Rank/BlockBonus/UntilUtc fields. Snapshots are captured before background serialization. Restore validates the whole candidate and rejects malformed or duplicate tails without partially replacing the live pool. Old rank/block/deadline captures are not recomputed or assigned a new schema.
