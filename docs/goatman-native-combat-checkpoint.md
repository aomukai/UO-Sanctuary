# Goatman timed native combat checkpoint

Reference: owned D2R Reign of the Warlock **3.3.93847**, with the approved NPC Frenzy/Cleave adaptation. Implementation and focused native verification pass: **21 native markers, three authenticated sessions, three boots, two reloads and three saves**. `GoatmanNativeCombat` owns one in-flight action for an original registered demon. Its action-service binding takes the existing GenericPet root's skill/base-mode choice, resolves the actual NPC and captures its own birth rank, pose, target and animation clock. It does not select targets or replace source AI. Basic attacks, Stun and Berserk use the existing primary attack animation and start-time allocator. Their original hit/damage/mitigation packet survives windup unchanged until the ordinary contact receiver. Berserk retains its existing timed startup and release self-state. Frenzy and Cleave use the already-approved action scheduler, release-time allocation and persistent own Frenzy state.

Each action retains an exact source-frame/UTC phase using a local animation epoch, including long-lived world frames. No mana is spent. A contact is claimed before callbacks; duplicate observations cannot repeat it. Completion returns only the action's still-current registered mode to neutral. Movement, control effects, owner disconnect/inactivity, facet or target loss and external mode changes cancel remaining work and consume any unused prepared packet. A cancellation cannot overwrite a different external mode. The caller still owns the advancing world clock; this executor does not introduce a timer, event-number mapping or persistence registration.

The approved action component now retains the registered FP16 source origin and source-cell aim. Its fan geometry, recipient ordering and interruption checks use those positions instead of reconstructing them from rounded native tiles. This is the same position authority already used by qualified walking and melee geometry. A movement smaller than a source cell can therefore cancel an old attack even when the native tile is unchanged. A live action guard also rechecks mode/control state between Cleave recipients.
