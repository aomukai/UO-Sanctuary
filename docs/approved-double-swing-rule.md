# Approved Double Swing startup rule

The user approved **“Approve this explicit Double Swing rule”** in reply to question `call_9156a4e3206248f3a18956c97a08ba01`. The exact prompt and answer are retained in [the decision record](../tools/reference/double-swing-start-decision.json).

Double Swing requires two eligible melee weapons and attacks with the primary, then the secondary, at the pinned SQ11 events. It uses the existing shared dual-weapon timing with the skill table's 50% skill-speed bonus. Each released strike pays the fractional table cost: 1 mana at effective rank 1, decreasing to zero at rank 9. Insufficient mana uses an ordinary attack. Cancellation stops the remaining strikes and does not refund released strikes.

This is an explicit Sanctuary adaptation for the missing modern startup/timing/payment contract. It does not certify D2R's compiled start68, current paired IAS/WSM quirks or full engine/world/client parity. Existing native pair eligibility and unsupported item/recipient guards remain. Ordinary weapon contact, Bash hard-point synergy, source-guid targeting and event/hand identity must reuse their existing shared implementations.
