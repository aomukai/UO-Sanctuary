# Confuse checkpoint — implementation in progress

Reference: **D2R Reign of the Warlock 3.3.93847**. Approved Sanctuary deviations take precedence. This draft has compiled, but its native verification is not accepted yet; no complete skill/class or deployment is claimed.

Confuse now has a candidate learned casting path with 13-mana release, source radius `6 + (rank − 1)` and duration `250 + 50 × (rank − 1)` frames. Configured owner-facet difficulty divides the duration by 1/2/4 before curse resistance. The visible curse makes the recipient neutral, rather than a friendly converted minion. Players and monsters can still attack it; it gains no player ownership or friendly immunity.

The pinned callback sets a generic monster target override and a separate AI-reset deadline after successful curse allocation. Removing or replacing the visible curse restores alignment but does not clear this independent override. `MindAiState`, stored outside the curse in the existing profile persistence, retains that deadline, the source-algorithm seed and target-selection metadata. The mode-3 source selection samples one low RNG bit to select an opposing alignment temporarily, scans, restores the original alignment and clears the override if it finds no target. The new controller feeds the existing native acquisition and ordinary species AI, rather than replacing their abilities with an always-nearest-monster loop.

The [source review](../tools/reference/confuse-source-review.json) pins ten complete legacy bodies and current table rows. It is explicitly static review, **not execution of the complete source engine**. Native acquisition cadence, scan ordering/threat/LOS, faction mapping, shared RNG ownership, target-node/event chronology and current-executable parity remain adapters or unverified. The actor-local stream uses `SourceRandom`; it does not recover the historical D2 seed or establish a unified NPC RNG stream. Unmapped native candidate alignment is excluded. Legacy bare Confuse saves have no recorded separate override deadline, so their full mode-3 migration remains unverified.

Two existing shared consumers needed correction. `GraveyardUndead.IsEnemy` bypassed the shared allegiance hook by calling Conversion directly; it now uses that existing hook while retaining the native home/ordinary-target rules. The old Dim Vision/Terror fixtures also lacked Confuse's runtime neutral alignment. The pinned do30 AI gate rejects neutral recipients, so those expectations now reject replacement while an ordinary curse such as Weaken can restore alignment. Confuse cannot refresh an already neutral recipient through its Evil-only entry gate. These are source-based corrections, not newly approved Sanctuary deviations.

Mind Blast is related mind-control infrastructure with a distinct contract: the pinned callback requires Evil alignment and sets Conversion/Good alignment. The shared Conversion service therefore rejects an active neutral Confuse recipient for Mind Blast conversion. Existing Mind Blast regression is included in the candidate checks; its user-observed damage-on-conversion and no-stun/no-knockback success behavior is preserved.

The candidate tests cover cost/radius/duration goldens, facet versus spawn difficulty, neutral attackability without ownership, AI-curse rejection, ordinary-curse replacement with retained independent deadline, player/monster faction selection, source-algorithm draws, no-target override clearing, saved and legacy shapes, right/quick input and autonomous NPC combat. Focused verification is still running; exact accepted scope will be recorded after terminal results and artifact validation. Source damage/experience credit, unsupported AI coexistence, native scan-gate edge cases and post-load autonomous target selection remain open.

Attract still uses the earlier continuous-radius adapter. Its do59 source writes separate target overrides to eligible neighbors before attempting the selected target's protected curse. It needs the independent-target/deadline model next; it is not implemented or certified by this Confuse draft.

Effects/audio continue using identified generic curse placeholders. `curseconfuse`/`cursecast` and talent/hotkey icons remain separately needed in [effects](skill-effects.md) and [icons](skill-icons.md). Pet upgrades and actual-safe-area parking remain queued. The standing roadmap workflow is to inspect related existing skills, helpers and tests before adding new machinery.
