# Psychic Ward learned cast and incoming reactions

Psychic Ward is admitted as the fifth Warlock handler, using the explicitly approved Sanctuary rule against D2R Reign of the Warlock 3.3.93847. Handler coverage is **214/240**, Warlock **5/30**. This does not certify a complete class or all current D2R behavior. Approval is recorded in [the decision](../tools/reference/psychic-ward-reaction-approval.json); it supersedes the earlier proposal's disabled-input status.

The ordinary self-cast uses the existing Warlock SC clock and table mana payment once on release. Right-click and quick keys work without an enemy cursor. Warlock mouse bindings now follow the pinned flags: Ward is right-only; Ring of Fire, Lethargy and Apocalypse retain their left/right flags. Allocation failure, cancellation and late mana failure preserve the tested group/payment behavior. Ward refuses Energy Shield coexistence while that interaction remains unqualified.

The native damage packet carries its own pre-absorption Ward ticket. Successful hostile NPC physical melee contacts react once through the shared incoming-return service after attacker returns and before slow, Life Tap, leech, Thorns and life loss. Fully absorbed and exhausting hits still react. Misses, ranged hits, purely elemental contacts and spells do not trigger the stun. Native armor-ignore physical packets still consume the Ward pool. Existing non-Ward callbacks retain their fallback; there is no global hit cache, new timer or production save format.

Verification uses an isolated native build and disposable worlds, with **24 passing markers across three boots, two reloads and three saves**. Eleven AOS packet cases per original character cover full absorption, exact depletion, fractional overflow, armor-ignore and exclusions. Direct class weapon/spell delivery and actual landed/nonlanded native swings also pass. Six authenticated right-click/quick-key sessions exercise natural timers and automatic hits against their newly created wards. Original Warlock/Witch actors retain pools of 641/642 FP256 units, captured rank/stun, wounds and mana through both reloads. Regeneration isolation is confined to named test fixtures.

Native patch 0073 changes two UOContent files; Server/host assemblies are unchanged. Native, content and integration builds pass with zero warnings/errors. The isolated client rebuild carries only the shared self-target metadata change, retains all 43 patches and passes exact reverse/forward source comparison; it reports 44 warnings and zero errors. No optional audit, dependency update, broad historical matrix rerun, new process-memory capture or deployment was performed. The first failed native attempt is retained: it exposed the Warlock mouse-binding gap, corrected before the accepted run.

Accepted build IDs: native/client 1, content/integration 2, source snapshot 2, native run 2. Detailed hashes and preservation checks are in [the receipt](../tools/reference/psychic-ward-cast-native-evidence.json).

Still unverified: actual graphical client interaction/rendering, PvP/player attackers, Energy Shield coexistence, legacy non-AOS paths, special native damage modifiers and exact protected current event37/40 semantics. Those are explicit limits rather than invented parity. Normal demon startup remains unapproved; unrelated blocked skills remain separately documented. Installed artifacts, saves and configuration are preserved. Effects/audio and talent/hotkey icons remain in their separate existing placeholder backlogs; no final assets were generated.
