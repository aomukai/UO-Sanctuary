# T08 — ordinary equipment recipe book

Approved T08 scope: defer exotic material recipes and use the native/analogue baseline below. The original eighteen recipes remain unchanged. The versioned runtime catalogue contains all603 recipes.

This covers 201 ordinary identities / 603 recipes across all three tiers. The ten exotic recipes are deferred by explicit user decision. It excludes jewellery (T17), cosmetic layers (no combat tiers), named rewards/variants, and the ten exotic material identities listed below. It includes all standard-material identities currently marked ordinary in the equipment catalogue plus the five existing potion tabards. Native racial/gender/class equipment restrictions remain.

Normal ingredients and requirements are listed below. Exceptional costs 2× each ingredient; Elite costs 3×. For Normal requirement `n`, Exceptional requires `80 + ceil(30n/80)` and Elite `110 + ceil(10n/80)`. New Normal requirements round native minima upward and cap at80. Each recipe keeps its native chance-window width, or an explicit analogue. Prepared recipes requiring120 skill use at least1% success chance at that exact cap; native smithing would otherwise give zero. The120 requirement still applies. Material-specific minimum skill still applies. Native log quantities become processed boards. Wood equipment moves to Fletching; bone equipment moves to Tailoring.

The pinned source links require156 distinct higher-tier reference rows. Claws use the source h2h→h2h2 subtype transition; Circlet shares the source Tiara/Diadem upgrades. These are catalogue details, not new design questions.

Native secondary ingredients are retained, including gems, bark and feathers. Their ordinary acquisition remains subject to the supply/loot cards; crafting tests grant fixture ingredients. Missing native recipes use the named analogue or the explicit authored baseline. All numbers remain versioned tuning data. Potion tabards are physically cloth and retain their existing row capacities independently of Normal/Exceptional/Elite base tier.
