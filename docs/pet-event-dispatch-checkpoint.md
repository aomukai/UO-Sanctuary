# GenericPet monster timed-event dispatch

2026-11-09 JST. Reference: **D2R Reign of the Warlock 3.3.93847**. Coverage remains **213/240 handlers, Warlock 4/30; no class certified**. The prepared event store can now execute a supplied event chain through the current monster router, including callbacks that remove themselves or another pending event. Automatic world ticking, global chain selection and the full AI entry remain unfinished.

**Reference discovery.** A bounded 145-byte candidate at `32f900` proved to free the queue and slab chain; it was rejected as a dispatcher. A separate complete 722-byte body at `32edd0` invokes the actual monster event router `3de390` (324 bytes) and the already-qualified remover. Its code establishes dispatch semantics; address proximity alone was not used as proof. The router's pinned table at `1723f00` links type-2 AITHINK to `43b0c0`. That full 1,096-byte entry is now captured, along with its 15-slot table, for subsequent integration. Four read-only captures read 6,814 bytes including validation. No target input, memory write or protection change was performed.

`GenericPetTimedEvents.Dispatch` accepts an explicit starting node and timed/all-events branch. It walks toward newer entries using the same saved cursor as the source. The timed branch invokes only entries whose due frame **equals** the supplied frame; it does not silently rescue overdue entries. Timed entries are released after a returning callback. The other branch invokes every supplied entry regardless of frame and retains it unless removal was requested; this verifies that processor branch without claiming the separate infinite-list producer or global caller.

Before a callback, the event receives processing flag 1 and the cursor points to its next candidate. Removing the current processing event sets flag 8. Removing the upcoming candidate immediately repairs the cursor to that candidate's predecessor. After a callback the processor clears flag 1, performs the required release and reads the repaired cursor. New events use the already-qualified producer; they do not automatically enter the currently saved traversal. Nested dispatch, throwing handlers and raw global cursor/allocator equivalence outside the supported chain remain unqualified.

`GenericPetMonsterEventRouter` preserves the current table and raw state gate for actual monster units. Types 3, 4, 5, 8, 9 and 12 bypass the state gate. Other types validate the selector and suppress their handler when table count >1, an available root has negative +1c and mask 0x2 at +b30, the unit lacks flag 0x10000 and its mode is neither 0 nor 12. Null table slots 4, 11, 13 and 14 have no default callback. The three payload words reach the supplied typed handler unchanged. No native status meaning or missing live metadata is inferred from those raw fields.

**Source comparison:** 36 focused sequences run the complete 722-byte executor and 324-byte router with the retained producer/remover/idle bodies, 2,842 loaded bytes including inline data. Cases cover empty chains, exact/early/late frames, selected starting nodes, same-bucket collisions, repeated all-event passes, self/upcoming/farther removal, allocation during callbacks, idle replacement, all 15 table slots, state-gate boundaries and selector refusal. Callback actions execute the actual captured producer/remover in the offline emulator. Event handlers are declared returning services; the newly captured full AI entry is not executed or certified by these comparisons. Non-null callbacks and their opaque validation remain outside this null-callback scope.

**Native composition:** each original Goatman, Tainted and Defiler receives an explicit due AI event, a later event in the same 64-frame bucket and a non-AI entry. The returning fixture handler runs that original demon's existing prepared root against the **same store**. The root requests removal of its processing event, removes the upcoming event, retains the other entry, finishes its typed command and publishes stored control words. The dispatcher then releases the processing event without running the removed candidate. Warlock/Witch ownership, birth snapshots, fractional wounds, typed commands and six root updates per original survive two real reloads. The event store is transient and recreated by the fixture; queue persistence and actual timed world execution are not claimed.
