# Shadow Shock Web field checkpoint

Mechanical reference: **D2R Reign of the Warlock 3.3.93847**, with approved Sanctuary deviations first. This is an internal field implementation; **208/240 public handlers, Assassin 28/30**, with both learned Shadows still disabled. The approved actual-dual-claw Shadow Weapon Block policy remains implemented and verified separately.

Both original Shadow species now produce Shock Web using the existing lob/scatter, ground-field pool and cast/target leases. Own rank and hard Fire Blast points determine scatter; real child units receive independent seeds from the existing saved world allocator, without consuming caster RNG. Air shards do no damage. Landing captures retained rank, the Shadow's own sentry synergy and lightning mastery/pierce into the ground packet. Owner mana, potion additions and gear never supply this packet. Ground contacts spend their 25-frame cast lease before damage/avoidance, roll the child seed, and use the shared typed NPC lightning receiver. Separate throws retain separate leases. The soft-hit packet refreshes the recipient without requesting ordinary get-hit mode; lethal damage still follows the shared death path.

The optional NPC source payload extends the shared version-0 field records; null payloads are omitted from legacy player JSON. Restore now validates complete shard and lease candidate dictionaries before replacing the live pool, so malformed tails cannot partially discard existing player or NPC fields. The existing player Shock Web checks remain in the focused cohort.
