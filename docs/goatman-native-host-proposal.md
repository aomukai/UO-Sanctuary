Status: **approved Sanctuary adaptation** — “Approve the tested native-host mapping (Recommended)”. Decision: `tools/reference/goatman-native-host-approval.json`. Reference: owned D2R Reign of the Warlock **3.3.93847**. This proposal includes the [prepared native room/search mapping](goatman-native-search-proposal.md) and composes the existing source AI, movement, follow, warp, animation and ordered NPC damage kernels. It does not claim recovery of the unavailable D2R global world caller or fresh dynamic-path constructor.

## Concrete native rules

- New Goatmen use their pinned two-cell ground footprint. The proposed fresh native path is centered on the actual legal UO position, with coordinate-membership flag1, mask60=0x100 and open-door ground mask64=0x3401; unused constructor fields start empty. These are explicit host defaults, not proof of the current D2 constructor. Normal AI header/control startup remains the previously approved tuple. Other demon species are not assigned these defaults.
- The current normal GenericPet descriptor148/type0 runs through the actual AI entry and preprocessing before the existing root. It reads the original saved header, command and control words. The existing native room/search/scoring mapping selects enemies; no simpler targeting AI is substituted. Native game-prefix bytes and the unowned gather scratch tail use explicit zero adapter inputs for this normal profile. Unknown overrides, queued functors, nonempty legacy saved-follow context and uninterruptible-deferred scheduling refuse rather than execute guessed behavior.
- Source movement preparation, approach attempts and all six follow modes use their existing kernels. Mode requests plan against the actual UO facet floor/occupancy with the existing source point-path algorithms. A zero path override means type13 and a zero budget means five source points; explicit overrides use their supported types, including bounded straight/AStar repair and wall follow. Planning uses the facet surface; movement still updates registered 32-cell room graphs and FP16 coordinates. The reconstructed initializer remains supplementary source evidence, so adopting it here is a native path-policy decision.
- Both walking/running requests use the owned Goatman walk animation and its pinned velocity8, which equals its pinned Run value. Captured movement bonuses, own Frenzy, Vigor and existing slows feed the shared speed helpers; Decrepify retains the source run-to-walk fallback. Primary-byte241 is read from the authenticated current monstats row, not guessed from Gargoyle art. Source standing-block mask64 maps to Sanctuary's existing allied-overlap rule and requests the source escape movement when blocked. Native UO region identity supplies follow-region comparisons; accepted movement endpoints supply owner destination, without predicting an unread next step.
- Recovery warp uses the source warp/placement orchestration. Its unrecovered region search is replaced by the existing bounded nearby search within four source cells of the owner, then the source fallback order. All placement uses real floor/space and registered room/update transactions. The source +0x128 warp flag is published on the actual saved actor. No resource recovery, rank recapture or Frenzy refresh is attached to warp.
- Actual closed UO doors touching the native actor's one-tile neighborhood expose the door collision/metadata context. Source preprocessing chooses the closest door (serial ties), uses an unlocked door through native `Use`, and applies its five-frame pause. Locked doors remain locked. This is the explicit object-world mapping; no D2 object class is inferred from a UO art ID.
- The clock uses25 source frames/second and the shared chronological bucket dispatcher for AI events. Each admitted active frame runs one regeneration step, movement or the existing timed attack, then due AI events. Action and movement completion rearm a future think. Basic/Stun/Berserk retain start-time packets; Frenzy/Cleave retain their approved contact-time allocation and own charge rule. No demon/owner mana is spent by NPC actions. Existing source stun preprocessing pauses for three frames; freeze/native paralysis/hit recovery cancel unfinished work and rearm after the pause.
- Logout, inactive class, safe-area parking and server reload cancel unfinished movement and attack delivery, skip elapsed clock phase, and rearm a future AI event only after admission. There is no offline combat or catch-up healing. Existing wounds, birth snapshots, current life percentage on difficulty changes, source control/commands, combat randomness and absolute buff deadlines remain governed by their existing stores. The candidate clock snapshot records only its phase; in-flight packets are deliberately not replayed.
- On return/travel, the real persistent roster restores a legal native body position. Replacement source room graphs are validated before publishing; the original header/control/commands and raw warp flags survive rebind. Existing Death Mark placement is authoritative: a changed registered path cancels stale motion/actions and retains Death Mark's destination, command and next-AI delay. No fresh birth snapshot is taken.

The world/search order, untagged wilderness fallback and actual town/allegiance/LOS mappings remain those described in the included search proposal. Unsupported branches stay explicit. The candidate covers an original normal Goatman; it does not silently convert legacy or other-species controllers.
