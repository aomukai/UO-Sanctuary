# Iron Golem equipped birth graph

Reference: D2R Reign of the Warlock **3.3.93847**, with approved Sanctuary deviations first. Branch: `codex/iron-golem-birth-graph`. This advances the [numeric birth preparation](iron-golem-birth-checkpoint.md); it does not enable the learned cast or finish Necromancer.

`IronGolemBirthGraph.Apply` now applies birth operations through the existing `EquipmentStatValues` and `EquipmentStatGraph` services on an already equipped NPC graph. It writes level first, adds monlvl armor/AR, reads recalculated life, applies passive and aura lists, writes base maximum/current life and then attaches absorption-aware Summon Resist. It binds the current thorns state **36** through the existing metadata table. Value-change callbacks remain active throughout; no final totals are fabricated by overwriting the graph's accrued arrays.

The integration fixes the earlier preparation boundary: an item's life-per-level value can change when the base helper sets the pet's level. Reading life immediately after equipment attachment would therefore be too early. The preparation contract now requires life after the base helper. Duplicate application is refused; a partially written graph must be reconstructed before retry, preventing duplicate permanent passives.
