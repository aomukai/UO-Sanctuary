# Warlock direct damage and Health Link

Reference: **D2R Reign of the Warlock 3.3.93847**, with the approved Sanctuary rules for Health Link and each affected talent taking precedence. The old accepted gameplay DLL reproduced Apocalypse's gap: 4,300 FP256 primary damage, zero of 2,279 expected shared damage, and an explicit missing-components fault. That baseline is frozen.

Apocalypse, Blade Warp, Hex: Purge and Sigil: Death now deliver their existing settled non-poison components to the shared health boundary. Primary damage calculation, capture, RNG, temporary resistance, absorption, payment, timing and once-only allocation/claim rules retain their existing paths. Poison remains in the primary total and is excluded from link copying.

Purge and Sigil: Death already suppress item events during their bursts. They now opt their root direct health notification into the existing shared API, as Blade Shield does. This permits Health Link without enabling item callbacks or recursive Purge bursts. Secondary shared packets retain default suppression. No shared API, event subscriber, numeric table or save format changes.
