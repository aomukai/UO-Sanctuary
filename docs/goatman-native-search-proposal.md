# Goatman native room and enemy-search mapping

Reference: owned D2R Reign of the Warlock **3.3.93847**. The current source traversal descriptor1, search wrapper, validity/priority/size ray, target scorer and decision root are reused. This is a **prepared Sanctuary native-world adaptation**, with **21 native markers, six authenticated sessions, three boots, two reloads and three saves passing**. It does not enable automatic AI or learned summoning.

`GoatmanNativeSearch` builds a read-only decision projection from actual same-facet mobiles and the existing registered 32-source-cell room layout. It visits the enclosing three-by-three rooms in coordinate order and each room's units in native serial order through the existing source traversal algorithm. Descriptor1 remains its pinned kind0/no override; proxy and monster-owned-follower descriptors are explicitly unsupported. Native room/list ordering is a proposed stable Britannia mapping, not a claim of D2 room-creation ordering. Membership changes during a traversal are refused; a fresh projection is built for each decision.

Registered Goatman positions use their actual source cells and FP16 grid fields. Other native mobiles use their committed native tile endpoints. UO supplies accepted movement endpoints, not a predicted next continuous D2 path. Native serials, original master links and saved historical corpse GUIDs use the existing identity services. A dead historical target is represented as dead and rejected from this attack-only search rather than exposed as loot or confused with a living actor. No corpse skill eligibility is granted.

Allegiance, visibility, targetability and safe-area exclusions reuse Sanctuary's actual `ClassCombat.IsHostile` and town rules. Controlled/summoned allies, vendors, invulnerable/dead actors and actors on another facet cannot become enemies. Source monster/secondary metadata and source size-ray endpoint shrinking remain in use; actual native LOS resolves the resulting endpoints with their respective heights. The native encounter grades supply their existing champion/unique/superunique classifications for priority. There is no invented D2 alignment stat node or imported owner piercing in this adapter.

Britannia has no D2 wilderness level tags. Search rooms therefore carry the untagged sentinel, leaving the optional D2 level-specific approach threshold absent; the existing search falls through to its ordinary LOS branch. Root town checks map actual safe areas to the source town branch; wilderness remains untagged. Native targets do not pretend to carry an undocumented D2 AI shortcut flag. These mappings need an explicit adaptation decision before automatic admission. Unbound corpse/buff states, point-path collision, object/missile/tile positions, proxy/monster-owner descriptors and heightless rays refuse rather than silently report plausible defaults.

Owner combat references pass through the source stale-path refresh. A rejected native pointer is cleared in its real native combat store and the same path view, so an earlier wrapper snapshot cannot resurrect it. The original source owner-bias identity and strict tie comparisons remain unchanged. `Bind` composes the actual world projection with the already-qualified root and caller-supplied execution/follow/clock leaves; it does not replace them with a new AI.
