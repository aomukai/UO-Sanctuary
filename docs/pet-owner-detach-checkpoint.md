# Player pet-store detachment

Reference: D2R Reign of the Warlock **3.3.93847**, with approved Sanctuary deviations first. This checkpoint implements current owner detachment and its store/context lookups. Native death, count/status effects and automatic summon admission remain separate.

`GenericPetOwnerDetach.Run` implements retained `35c970` (553 bytes). It validates player data, caches the original store and pet GUID, finds the source pet type, preserves the special raw type-7 callback exception, and reads the bucket using the game selector after that callback. It marks only the first matching node inactive without discarding the upper flags. The subsequent data lookup re-reads the current pet GUID and player store. It then calls the mandatory status service, builds a structured notice before flushing the client, reads the client ID after flush, and preserves the final broadcast. Missing data and invalid contexts refuse explicitly; no D2 packet is sent to a UO client.

`GenericPetOwnerStore` implements actual type lookup `35d0e0` (293), bucket lookup `35b600` (95) and entry-data lookup `35d410` (326). Type/data searches include inactive entries and retain first-match ordering. Their player selector is distinct from the outer detachment's game selector. Bucket lookup rejects negative types before validating the selector. Empty buckets and absent buckets retain their different source outcomes. New mutable entries preserve the full flags DWORD and expose the existing iterator's low-byte view, so later enumeration observes the inactive marker without creating a second traversal algorithm. The adapter takes an explicit captured backing handle, matching the existing source iterator even if a callback changes the player’s store; a focused mutation control verifies the later bucket keeps its original backing.

Current packed-context getter `3706f0` (104) matches the expression already used by AI entry. `GenericPetPackedContext` now supplies both consumers. It requires its game even if the monster has an original snapshot, selects that snapshot only with the source data flag, and retains an explicitly supplied unwritten tail. Detachment uses only the established byte at bits 40–47; it does not infer a gameplay meaning for the remaining packed bytes. The query-data pointer is not read or changed by this helper.
