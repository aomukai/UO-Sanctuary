# Complete Rancor rule proposal

This is an **unapproved Sanctuary adaptation** for the protected Sigil: Rancor do61 recipient callback in **D2R Reign of the Warlock 3.3.93847**. Its known primary values and existing Confuse selector are implemented. The current callback does not establish chance cadence, stream ownership, refresh, group8 precedence or exact expiry. This proposal makes those choices explicit; automatic pulses and learned Rancor remain disabled.

Use the existing Sigil SC/FCR cast, target placement, 12-mana release payment, one-slot roster and approved lifecycle. A replaced marker keeps the shared terminal update. Capture its effective rank at creation. Existing rank-based missile bodies, marker lifetime and radius remain unchanged.

For each online, same-facet combat pulse from the existing six-frame driver:

- Claim the marker/frame before any recipient callback. A saved optional cursor prevents duplicate or reentrant application. Process recipients by serial in the inclusive marker-centered source radius: 4/6/8 units at ranks 1/10/20, with the existing height limit. Add no new recipient LOS test beyond shared Sigil targeting and hostility/visibility checks.
- Admit ordinary hostile, living, damageable NPCs through the existing aura mapping and AI eligibility. Exclude safe areas, controlled/summoned units, bosses/champions/uniques and other unsupported recipients. Unmapped native creatures and PvP remain separate coverage gaps.
- Apply physical weapon ED of 50% plus 5 percentage points per additional rank, and attack rate of 5% plus 1 per additional rank, for 12 frames (0.48 seconds). Do not divide this lease by difficulty. The existing additive weapon ED and final speed clamps apply. These primary bonuses apply even when the Confuse roll fails.
- Roll unsigned 0–99, succeeding below 75. Keep one saved stream per recipient, shared between its Rancor chance and existing Confuse-selector draws. Start the stream once for a new recipient; later ranks/casters continue it. Exact global D2R unit-stream interleaving is not claimed.
- A success installs or refreshes the independent neutral Confuse lease to the same 12-frame deadline and reopens target selection. Keep existing focus until the shared selector reacquires, respecting native scan gates. A failure advances the stream but preserves the previous AI deadline/focus; it cannot extend an older Confuse lease.
- A weaker primary rank is ignored without refreshing or drawing. Equal rank refreshes primary expiry and retains the original creator and stats, then makes the new chance roll. Stronger rank replaces creator/stats and uses that recipient's continuing stream. Rank is captured from the marker, not later gear.
- Preserve ordinary curses and AI. Existing live generic leases, Confuse, Attract, Dim Vision, Terror/Grim Ward, Taunt, Cloak blind, item fear and conversion retain priority over Rancor's independent lease. Rancor's primary stats stay independent. Rancor and Confuse are the two owned states in group8; preserving the existing ordinary effect rather than replacing it is an explicit adaptation. Lethargy remains independent.
- When Rancor's primary or AI lease expires, remove its expired contribution without restarting a timer or refilling state. Preserve its stream. Return to normal acquisition only when Rancor actually held an AI lease and no higher-priority controller owns the actor. A primary-only expiry does not interrupt unrelated combat, and new ownership/conversion retains its controller. An empty search alone does not end neutral alignment before the lease deadline.

The user's approved Sigil lifecycle is reused: owner death/deletion removes markers; logout or facet separation leaves markers where cast, suppresses pulses and lets lifetime continue. Return resumes one new pulse without catch-up. Existing recipient leases continue to their own expiry, without recovery/reset. No new gameplay timer, persistence identity or save version is introduced. Optional null-omitted metadata extends existing profiles. Markers and recipient overlays/audio/icons remain identified placeholders or separately pending assets.
