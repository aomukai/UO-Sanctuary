The prepared monster damage/contact pipeline now owns the existing Life Tap, packet absorb healing, flat attacker-takes-damage and percentage Thorns consumers. Life Tap receives the event physical value before the victim-life clip. Ordinary caller recovery follows clipping; supplied absorb healing follows recovery and is suppressed by death-delay state. Incoming fractional HP is then committed once. Flat return occurs at the attacked-in-melee phase, including misses/blocks. Percentage return is a separate later successful-hit phase; an attacker already killed by flat return receives no further percentage packet. The captured death result is consumed in the later return phase, without replaying incoming native `Damage` or subtracting HP again.

The existing outer melee-attempt scope records the flat dispatch, preventing its fallback from duplicating the return. `PaladinThorns.Prepared` retains immediate-consumer behavior through a shared flat helper.
