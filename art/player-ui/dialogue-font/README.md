# Dialogue typography

`Book.mul` is a bitmap font for ClassicUO generated by [make_dialogue_font.py](../../../tools/make_dialogue_font.py). English and German use IM Fell English Roman. Kana, Japanese punctuation, and kanji in the BMP portion of JIS X 0213 use the Japanese face from Noto Serif CJK Regular. The Classic setting uses the original client data's Unicode typeface.

- [IM Fell English source](https://github.com/google/fonts/tree/main/ofl/imfellenglish) · [SIL Open Font License](OFL-IM-Fell.txt)
- [Noto Serif CJK source](https://github.com/notofonts/noto-cjk/tree/main/Serif) · [SIL Open Font License](OFL-Noto-Serif-CJK.txt)
