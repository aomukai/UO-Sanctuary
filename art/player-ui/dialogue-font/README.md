# Dialogue typography

The dialogue font picker offers Blackletter, Classic, and Book. Blackletter is the default and pairs Germania One with Yuji Syuku for Japanese. Book uses IM Fell English Roman with Noto Serif CJK Regular for Japanese. Classic uses the original client data's Unicode typeface.

The bundled bitmap fonts are generated by [make_dialogue_font.py](../../../tools/make_dialogue_font.py). Generate Blackletter from the upstream TrueType faces and the checked-in Book bitmap. The generator copies missing glyphs from Book so its Japanese coverage is preserved. It uses Pillow and Fontconfig's `fc-query`.

```sh
python3 tools/make_dialogue_font.py GermaniaOne-Regular.ttf YujiSyuku-Regular.ttf \
    art/player-ui/dialogue-font/Blackletter.mul --fallback-mul art/player-ui/dialogue-font/Book.mul
```
