# Avatar portrait templates

The chooser has six groups of 56 finished portraits. Each group has three original PNG atlases in display order. The first two have four columns and five rows. The last has four columns and four rows. Each cell maps to one permanent template ID and to the native race, body, hair or horns, facial style, and dyes specified by [AppearanceTemplates.cs](../../../shared/AppearanceTemplates.cs).

The built-in ImageGen tool produced the atlases using the approved twelve-character Sanctuary sample for art direction. The game samples each painted portrait directly from its atlas. The same ID drives the in-world appearance, health gump, and player portrait in dialogue.
