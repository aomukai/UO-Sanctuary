## Generation prompts

Character frame

> Use case: ui-mockup. Asset type: a single finished raster backdrop layer for a classic isometric fantasy RPG character gump, to be composited with live game text and an equipment sprite. Make an original Ultima-inspired ('Ultima VII era') 1990s hand-pixelled interface surface, with compact dithered detail, dark oak, warm muted bronze, and aubergine shadows. Show a perfectly rectangular panel in a flat straight-on orthographic view, edge to edge on a wide 3:2 canvas, with a narrow fine brass-and-dark-oak border, clipped corner engravings and a hairline horizontal header divider at around 13% from top. The entire interior across both halves is open, blank, very dark warm umber / ink-stained leather, subdued fine texture, low contrast across the middle. Keep header and footer interiors blank too. Use a disciplined limited 16-bit-game palette and real small pixel clusters, no glows. Finish the rim all the way around. This is a runtime texture asset, not a screenshot. No icons, avatars, equipment slots, blotches, text, numerals, images inside the frame, perspective, painted objects, margins, backdrop, or watermark.

Journal book, with the repo-root principles and virtues image as its conceptual reference

> Use case: ui-mockup. Asset type: a single raster backdrop layer for an original Ultima-inspired Britannian journal gump for a 1990s-style isometric fantasy RPG. Input image 1 is a conceptual reference for a scholar's three-circle virtue index; use it only to set the medieval scholarly mood. Shapes and all labels will be drawn by game code. Build a clean straight-on opened small field journal, filling a wide 3:2 rectangular canvas right to the edges. A thin dark burgundy leather rim, restrained bronze corners, a visible but narrow dark seam exactly down the center, and two unmarked flat muted warm ivory parchment pages with subtle low-contrast age and a faint hairline border. Each page needs 90% blank space with level contrast for live UI. Original hand-pixelled 16-bit game art, selectively dithered, discrete color clusters, beautiful and practical at 640 pixels wide. No text, no marks on the pages, no symbols, no Venn diagram baked into the art, no hands, no objects, no surrounding scene, no 3D angle or background margin.

### ImageGen prompts

All four production images were made with the built-in ImageGen tool. The root reference `portrait.png` informed the framing and readability of the first sheet.

**Base portrait sheet**

> Create one original video-game UI texture atlas, exactly 4 columns by 6 rows of square portrait tiles, distinct faces. Warm hand-painted 1990s fantasy CRPG pixel-art portrait style, visible facial expression with deliberate square pixel clusters and warm directional lighting. Use the attached screenshot only as a reference for how readable and tightly framed the face is, never copy its character, text, frame, or other artwork. No labels, no grid lines, no margins, no border, dark uniform charcoal-brown backgrounds behind each tile. Each tile has the same strictly straight-on head-and-neck framing, centered on the exact tile centerline, with ears and scalp visible. Strict uniform feature registration for hair layers added in-engine: top of skull about 14% down the tile, eyes about 45%, nose tip at 58%, chin at 77%, shoulders just at bottom. No hair, no headwear, no facial hair, no earrings, no bodies, hands, props or clothing above the shoulders. Four visibly different individual faces per row, varying age and facial features. Row 1 human masculine, row 2 human feminine, row 3 elf masculine (subtle pointed humanlike ears), row 4 elf feminine (pointed humanlike ears), row 5 gargoyle masculine (warm copper or ochre humanoid stone-flesh, brow ridges, strong flat broad nose), row 6 gargoyle feminine (terracotta to ochre humanoid stone-flesh and softer swept brow ridges). No horns on the gargoyle bases, horns are a separate layer. Crisp evocative eyes and features, distinct faces, restrained retro-realistic proportions. Portrait canvas with 2:3 aspect ratio. The file will be sampled as a uniform 4x6 runtime atlas, so exactly four even columns and six even rows are mandatory.

**Bare-headed revision of the base sheet**

> Targeted revision to this 4-column by 6-row game texture atlas. Remove ALL painted scalp hair on every portrait in the FIRST FOUR ROWS and replace every bit of it with visible rounded BALD scalp on top and plain uniform background around the ears and shoulders. This includes every curl, fringe, sideburn, wave, ponytail, stray strand, and lock behind the neck. The runtime adds selectable hair; these MUST be cleanly shaved bare-skinned sample models, female and male alike. Preserve each recognizable face, eye shape, expression, apparent sex, pixel-art style and ears; preserve every tile placement, rows and columns and exact dimensions. Keep the bottom two gargoyle rows as they are. Bare smooth scalp arches across the central 65% of each top tile, behind forehead and ears, occupying approximately y=16% to y=35% of each tile, same scale on each head with room above. Replace clothing if needed only at the shoulders and keep the look warm. No added text or frames. Exactly 4 equal columns x 6 equal rows, preserve aligned portrait centers.
