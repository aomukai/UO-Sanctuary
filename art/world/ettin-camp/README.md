# Ettin camp bonfire

The built-in ImageGen tool produced [the transparent sprite sheet](bonfire-atlas.png). Run `python3 tools/build_ettin_bonfire.py` to pack its eight frames into ClassicUO loose statics. All frames share a ground anchor and render at one frame per 100 ms. The camp uses native props for the deer and hides.

## ImageGen prompt

> An original transparent RGBA pixel art SPRITE SHEET for Sanctuary, a 1990s isometric fantasy RPG. Show only the bonfire asset for an ettin hunting camp. Exactly eight separate animation frames arranged in a strictly regular four column by two row grid, equal cells across the entire landscape image. No borders, lines, grid marks, or words. All eight depict the SAME anchored stationary wood bonfire. Camera is isometric three-quarter top-down, 2:1 perspective. Base is a squat, stable stack of large dark split logs crossed like a low teepee, some glowing coal scraps. Faint chunky wood facets read clearly. The identical logs and coal footprint stay in the exact same position, geometry and scale in all eight images. Only the flames animate, swaying little toward either side, crest tongues twisting and changing, some small floating sparks. Height approximately one and a quarter times a game character, tapered upward, orange and rich amber outside, lemon yellow inner tongues and some subtle hot cream at foot. Retro hand-painted pixel-cluster rendering, accurate game item shading, deliberate sharp edges and restrained colors. No rock ring, brazier, human, monsters, pelts, other props, labels, ground plane, huge haze, background glow, smoke clouds, color matte or drawn shadows. True transparency completely surrounding each fire sprite, keep all flames and sparks inside each cell. Render each log pile in precisely the same anchored ground alignment in every cell so only rising fire looks busy in-game. Real game sprite animation atlas, all eight clearly distinct fire poses.
